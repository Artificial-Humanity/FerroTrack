# FerroTrack

A light AI-native issue tracking system for agentic workflows — built in Rust; the
backing store is under evaluation. Sibling project to
[FerroStep](https://github.com/Artificial-Humanity/FerroStep): FerroTrack is both the
out-of-the-box store FerroStep ships against and an issue tracker in its own right.
FerroStep's other ledger adapters remain supported; FerroTrack is the default, not the
only option.

**Status: pre-alpha, research phase.** The repository was created on 2026-08-28; see
[`notes/redb-research.md`](notes/redb-research.md) for where things stand.
