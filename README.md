# FerroTrack

A light AI-native issue tracking system for agentic workflows — built in Rust on
[redb](https://github.com/cberner/redb). Sibling project to
[FerroStep](https://github.com/Artificial-Humanity/FerroStep): FerroTrack is both the
out-of-the-box store FerroStep ships against and an issue tracker in its own right.
FerroStep's other ledger adapters remain supported; FerroTrack is the default, not the
only option.

**Status: pre-alpha.** The repository was created on 2026-08-28 and no product code
exists yet. [`north-star.md`](north-star.md) is where things stand. The research each
decision was made on is kept in private working notes, cited by name in
[`AGENTS.md`](AGENTS.md) rather than published here.
